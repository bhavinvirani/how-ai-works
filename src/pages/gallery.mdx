# Gallery

Every control on this site, live and operable. This page is the style guide, the
review surface for changes, and the place to check that a new instrument still
looks like it belongs.

Try it with the keyboard. Everything here works without a mouse, and anything
that stops working is a bug.

## Instruments

The real ones, exactly as they appear inside a unit. Everything below this
heading is a control; everything here is a finished teaching instrument built
out of those controls.

Find a rule set that scores perfectly on this week's inbox, then switch weeks.
The instrument searches all thirty-two combinations, so the "no set works" claim
is computed rather than asserted.

No right answer, only a score — and the thing it settles on is whatever the

Perfect on the sales it studied, ruinous on the ones it has not seen.

### Score it on what it never saw

Repairing a leaky split makes the score worse. That is the score becoming

### Turn the bar up and down

A detector that raises no alarms at all scores 99%.

### Set someone else's taste in films

Take the bend out and a stack of neurons collapses into something one neuron

### Hand out the blame

Every dial is told its share of one wrong answer, and the share is a product of

### Move around a map of meaning

Distance is similarity, and the same arrow means the same thing wherever you
start it from.

<MeaningMap client:visible />

One word swaps, and what the pronoun refers to swaps with it. Nothing else in

### Cut a sentence into the pieces a model reads

A rare name costs more pieces than a longer common one, and the letters inside a

### Watch one word ask the others

Each word's attention sums to one, so leaning harder on one word means leaning

### Aside

A short detour: a caveat, a bit of history, a misconception worth naming. Tone
changes the edge colour and the title together, never colour on its own.

<Aside title="This is not how it worked originally">
  Early systems split on spaces and punctuation. That falls apart on languages
  that do not put spaces between words, which is a large share of them.
</Aside>

<Aside tone="caution" title="Easy to get backwards">
  More tokens does not mean more meaning. A long word split into six pieces
  carries the same idea it always did — it just costs more to process.
</Aside>

### Checkpoint

Closes each unit. The question comes first, the answer stays folded until the
reader has had a go.

<Checkpoint question="Why would a model split an unfamiliar word into pieces rather than treat it as one new word?">
  Because its vocabulary is fixed and finite. A word it has never seen has no
  entry to look up — but the pieces do, so it can build a meaning out of parts
  it already knows.
</Checkpoint>

### Developer aside

Collapsed by default, because a general reader should never need to open it.
Tabs appear only for the languages an aside actually provides, and picking one
picks it everywhere else on the site too.

<DevAside>
  <Fragment slot="java">
    ```java
    var tokens = tokenizer.encode("tokenisation");
    // [1417, 5983, 367]
    ```

    The encoder returns ints, not strings — the model never sees the text again.

  </Fragment>
  <Fragment slot="python">
    ```python
    tokens = tokenizer.encode("tokenisation")
    # [1417, 5983, 367]
    ```

    Same idea: from here on, the model is working with numbers.

  </Fragment>
</DevAside>
